    3. "export API_KEY="dummy"

    4. Trước tiên tạo skill cho ubuntu đã
    5. Khi người dùng nhập yêu cầu liên quan đến gen unit test, tiến hành trích xuất các thông tin về source file cần test, expected coverage, max iteration và model. Giá 
    trị mặc định cho đối số expected coverage là 85, max iteration là 5, model là "claude-haiku-4-5" cho cả project sử dụng ngôn ngữ python và java.
    6. Sau đó kiểm tra đã có file architect.md chưa, nếu chưa có thì sử dụng slash /analysis_architect_and_framework để có được thông tin cần thiết ở trong file 
    architect.md
    7. Sau đó kiểm tra đã có file test tương ứng với file source code cần test chưa, file test sẽ có đường dẫn tương tự như file source code nhưng nằm trong thư mục tests, 
    nếu file test chưa có thì sẽ tự động tạo theo quy tắc file test sẽ có đường dẫn tương tự như file source code nhưng nằm trong thư mục tests. Ví dụ: file source code là 
    src/main/java/com/example/jpa_querydsl_demo/service/CompanyService.java thì file test là src/test/java/com/example/jpa_querydsl_demo/service/CompanyServiceTest.java
    8. Sau đó agent quyết định sử dụng command cho project python hoặc project java tùy thuộc vào tính chất của project được cung cấp. Lệnh cho project python và java đã 
    được cung cấp ở trên
    9. Với project python, đối số của thông tin coverage là "--coverageReportPath="coverage.xml" \ --coverageFormat="cobertura"". Với project java, đối số của thông tin 
    coverage là "--coverageReportPath="target/site/jacoco/jacoco.xml" \
      --coverageFormat="jacoco" \"
    10. Agent sẽ tự quyết định giá trị cho đối số --test-command tùy thuộc project. Ví dụ của project sử dụng ngôn ngữ python "--testCommand="uv run coverage run 
    --include=backend/service/resume_evaluation.py -m pytest test/test_single_file/test_resume_evaluation.py && uv run coverage xml" \", project sử dụng ngôn ngữ java 
    "--testCommand="mvn verify -P coverage -Dtest=ContactServiceTest" \".
    11. Trước khi thực hiện bất cứ lệnh nào liên quan đến keploy thì sẽ kiểm tra môi trường của project. Nếu project python thì kiểm tra môi trường đã có thư viện pytest, 
    pytest-asyncio, coverage chưa, nếu chưa thì sử dụng uv để cài với lệnh uv add. Nếu project java thì kiểm tra môi trường được sử dụng là maven hay gradle, cài các 
    dependencies cần thiết để thực hiện gen và chạy unit test với keploy gen
    12. Có script phù hợp với project python hoặc project java từ các đối số và 2 command ở trên, agent sẽ điền giá trị vào các đối số này, tức là script sẽ có các đối số 
    là placeholder để agent điền vào, có giá trị mặc định như trên nếu không điền
    13. Agent sẽ thêm thông tin của file architect.md vào keploy gen thông qua đối số --additional-prompt
    14. Agent tự điền giá trị cho đối số function-under-test nếu người dùng có yêu cầu trong prompt, mặc định là ""
    15. Agent tự điền giá trị cho đối số flakiness nếu người dùng có yêu cầu, mặc định là false
    16. Có hiển thị log trong quá trình chạy lệnh keploy gen
    17. Nếu có lỗi gì thì hiển thị toàn bộ log lỗi ra console
    18. thêm script chạy keploy gen với đầy đủ đối số phù hợp với project python hoặc project java từ các đối số và 2 command ở trên, agent sẽ điền giá trị vào các đối số này, 
    tức là script sẽ có các đối số là placeholder để agent điền vào, có giá trị mặc định như trên nếu không điền
